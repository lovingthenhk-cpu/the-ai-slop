# THE AI SLOP™

A handcrafted, satirical website about the absurdity of endless AI-ish content. Pure HTML, CSS, and vanilla JavaScript — **no API keys, no framework, no telemetry, no actual AI generation**.

## Play

- Slop Factory: switch themes, adjust nonsense, generate/share/save intentionally ridiculous quotes.
- The Feed: discover and like six varieties of nonsense; load more for infinity-ish scrolling.
- Slop Lab: lose imaginary braincells and calculate a statistically meaningless Slop Index.
- Slop Vault: browser-only saved quotes, JSON backup and shareable links.
- Slop Detector 3000: a deliberately fake, entirely local keyword-based content score (not an AI detector).
- Brainrot Bingo: a playable 5×5 buzzword bingo with saved board state and a high score.

Open `index.html` or deploy the repository root to GitHub Pages. Progress and preferences are stored in browser `localStorage` only.

Built as parody. No genuine facts or financial/medical advice are implied.

## Deployments

The project is hosted on [GitHub Pages](https://lovingthenhk-cpu.github.io/the-ai-slop/) from `main`. Releases v0.1–v0.5 were committed and deployed incrementally. Cache-busted CSS/JS URLs ensure each HTML release loads matching assets.
